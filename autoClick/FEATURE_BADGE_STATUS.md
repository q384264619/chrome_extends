# 插件Badge状态显示功能

## 🎯 功能概述

本次更新添加了**插件图标Badge显示**功能，让你即使在**关闭插件面板的情况下**也能：

1. ✅ **实时查看任务状态** - 在浏览器工具栏的插件图标上显示启用任务数量
2. ✅ **查看执行次数** - 鼠标悬停时显示详细的统计信息
3. ✅ **快速了解概况** - 通过颜色和图标快速判断整体状态

---

## ✨ 新增功能

### Badge显示规则

#### 1. 有启用的任务（绿色）

**显示内容**：
- **Badge文本**：启用的任务数量（如 `2`）
- **Badge颜色**：🟢 绿色 (#27ae60)
- **悬停提示**：
  ```
  自动点击助手
  启用任务: 2
  已完成: 1
  总执行: 15次
  ```

**适用场景**：
- 有任务正在运行
- 需要监控执行进度

---

#### 2. 所有任务已完成（蓝色）

**显示内容**：
- **Badge文本**：✓（对勾符号）
- **Badge颜色**：🔵 蓝色 (#3498db)
- **悬停提示**：
  ```
  自动点击助手
  已完成: 3/3
  总执行: 20次
  ```

**适用场景**：
- 所有单次触发任务都已完成
- 确认任务执行完毕

---

#### 3. 所有任务已禁用（红色）

**显示内容**：
- **Badge文本**：✗（叉号符号）
- **Badge颜色**：🔴 红色 (#e74c3c)
- **悬停提示**：
  ```
  自动点击助手
  所有任务已禁用 (3)
  ```

**适用场景**：
- 没有启用的任务
- 需要重新启用任务

---

#### 4. 没有任务（灰色）

**显示内容**：
- **Badge文本**：无（空白）
- **Badge颜色**：⚪ 灰色 (#95a5a6)
- **悬停提示**：默认标题

**适用场景**：
- 刚安装插件
- 删除了所有任务

## 🔧 技术实现

### updateBadge函数

```javascript
async function updateBadge(tasks) {
    // 统计任务状态
    const enabledCount = tasks.filter(t => t.enabled && t.status !== 'completed').length;
    const completedCount = tasks.filter(t => t.status === 'completed').length;
    const totalExecutions = tasks.reduce((sum, t) => sum + (t.executionCount || 0), 0);
    
    // 根据状态设置badge
    if (enabledCount > 0) {
        badgeText = `${enabledCount}`;
        badgeColor = '#27ae60'; // 绿色
        
        await chrome.action.setTitle({
            title: `自动点击助手\n启用任务: ${enabledCount}\n已完成: ${completedCount}\n总执行: ${totalExecutions}次`
        });
    } else if (completedCount > 0) {
        badgeText = '✓';
        badgeColor = '#3498db'; // 蓝色
    } else {
        badgeText = '✗';
        badgeColor = '#e74c3c'; // 红色
    }
    
    // 应用badge
    await chrome.action.setBadgeText({ text: badgeText });
    await chrome.action.setBadgeBackgroundColor({ color: badgeColor });
}
```

---

### 自动更新机制

#### 触发时机

1. **任务执行后**
   ```javascript
   async function updateTaskAfterExecution(task) {
       // ... 更新任务状态
       await chrome.storage.sync.set({ tasks: allTasks });
       
       // ✅ 自动更新badge
       await updateBadge(allTasks);
   }
   ```

2. **Storage变化时**
   ```javascript
   chrome.storage.onChanged.addListener(async (changes, namespace) => {
       if (namespace === 'sync' && changes.tasks) {
           const newTasks = changes.tasks.newValue || [];
           await updateBadge(newTasks);  // ✅ 自动更新
       }
   });
   ```

3. **插件初始化时**
   ```javascript
   async function initializeTasks() {
       await scheduleAllTasks(tasks);
       await updateBadge(tasks);  // ✅ 初始化badge
   }
   ```

## 🐛 故障排查

### 问题1：Badge不显示

**可能原因**：
- 插件未正确加载
- manifest.json缺少权限

**解决**：
1. 重新加载插件
2. 检查manifest.json包含：
   ```json
   "permissions": ["storage", "alarms"]
   ```
3. 查看Console是否有错误

---

### 问题2：Badge数字不正确

**可能原因**：
- Storage同步延迟
- Badge更新逻辑未触发

**解决**：
1. 刷新插件面板（重新打开）
2. 查看Background Console：
   ```javascript
   [Badge] 更新完成 - 启用:2, 完成:1, 总执行:15
   ```
3. 确认updateBadge被调用

---

### 问题3：悬停提示不显示详细信息

**可能原因**：
- setTitle未正确调用
- 浏览器缓存问题

**解决**：
1. 重启浏览器
2. 检查代码中是否有：
   ```javascript
   await chrome.action.setTitle({ title: ... });
   ```
3. 确认setTitle在setBadgeText之前或之后调用

---

### 问题4：Badge颜色不变

**可能原因**：
- setBadgeBackgroundColor失败
- 颜色值格式错误

**解决**：
1. 检查颜色值是否为十六进制格式（如 `#27ae60`）
2. 查看Console是否有错误
3. 尝试手动设置：
   ```javascript
   chrome.action.setBadgeBackgroundColor({ color: '#ff0000' });
   ```
