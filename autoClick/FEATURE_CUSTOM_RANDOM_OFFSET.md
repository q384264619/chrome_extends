# 用户自定义随机时间偏移功能

## 🎯 功能概述

本次更新将**随机时间偏移的最大值**从固定的±30秒改为**由用户自定义**，让用户可以根据自己的需求灵活调整随机范围。

---

## ✨ 新增功能

### 用户可配置的随机偏移范围

**配置位置**：任务配置页面 → 执行时间设置 → 设定具体时间后显示

**输入框**：
- **标签**：随机时间偏移（秒）
- **默认值**：30秒
- **最小值**：0秒（表示无随机）
- **最大值**：300秒（5分钟）
- **提示**：±N秒，0表示无随机

**示例配置**：
```
设定时间：09:00
随机偏移：60秒
实际执行：08:59:00 到 09:01:00 之间
```

### 2. popup.js - 表单处理

#### getFormData函数

```javascript
if (data.timeMode === 'specific') {
    data.execTime = document.getElementById('execTime').value;
    
    // ✅ 添加随机时间偏移设置
    const randomOffsetInput = document.getElementById('randomOffsetSeconds');
    data.randomOffsetSeconds = randomOffsetInput ? parseInt(randomOffsetInput.value) || 0 : 30;
} else {
    // 如果没有设定具体时间，随机偏移无效
    data.randomOffsetSeconds = 0;
}
```

**逻辑**：
- 读取用户输入的随机偏移值
- 如果未输入或输入无效，使用默认值30
- 如果没有设定具体时间，设置为0（无效）

---

#### fillForm函数

```javascript
if (task.timeMode === 'specific') {
    document.getElementById('setTime').checked = true;
    document.getElementById('timeField').classList.add('show');
    document.getElementById('execTime').value = task.execTime || '';
    
    // ✅ 填充随机时间偏移
    const randomOffsetInput = document.getElementById('randomOffsetSeconds');
    if (randomOffsetInput) {
        randomOffsetInput.value = task.randomOffsetSeconds !== undefined ? task.randomOffsetSeconds : 30;
    }
}
```

**逻辑**：
- 编辑任务时自动填充之前保存的随机偏移值
- 如果任务没有该字段，使用默认值30

### 3. background.js - 调度逻辑

#### calculateNextRunTime函数

```javascript
if (task.timeMode === 'specific' && task.execTime) {
    const [hours, minutes] = task.execTime.split(':').map(Number);
    targetTime = new Date(now);
    targetTime.setHours(hours, minutes, 0, 0);

    // ✅ 添加随机时间偏移（使用用户设置的值）
    const maxOffset = Number(task.randomOffsetSeconds) || 30; // 默认30秒
    
    if (maxOffset > 0) {
        // 生成 -maxOffset 到 +maxOffset 秒之间的随机数
        const randomOffset = Math.floor(Math.random() * (maxOffset * 2 + 1)) - maxOffset;
        targetTime.setSeconds(targetTime.getSeconds() + randomOffset);
        
        console.log(`[任务调度] 设定时间 ${task.execTime}，用户设置最大偏移 ${maxOffset}秒，实际随机偏移 ${randomOffset}秒，实际执行时间 ${targetTime.toLocaleTimeString()}`);
    } else {
        console.log(`[任务调度] 设定时间 ${task.execTime}，无随机偏移`);
    }

    // 如果今天的时间已过，设置为明天
    if (targetTime <= now) {
        targetTime.setDate(targetTime.getDate() + 1);
        // 明天的时间也需要添加随机偏移
        if (maxOffset > 0) {
            const tomorrowRandomOffset = Math.floor(Math.random() * (maxOffset * 2 + 1)) - maxOffset;
            targetTime.setSeconds(targetTime.getSeconds() + tomorrowRandomOffset);
            console.log(`[任务调度] 调整为明天，再次添加随机偏移 ${tomorrowRandomOffset}秒`);
        }
    }
}
```

**关键点**：
1. **读取用户设置**：`const maxOffset = Number(task.randomOffsetSeconds) || 30`
2. **动态计算范围**：`Math.floor(Math.random() * (maxOffset * 2 + 1)) - maxOffset`
   - 例如：maxOffset=60 → 范围是 -60 到 +60
   - 例如：maxOffset=30 → 范围是 -30 到 +30
3. **支持禁用**：如果 maxOffset=0，不添加随机偏移
4. **跨天处理**：明天也使用相同的 maxOffset 重新计算随机偏移
5. **详细日志**：记录用户设置和实际使用的偏移值

## 💡 设计理由

### 为什么让用户自定义？

**原因**：

1. **不同场景有不同需求**
   ```
   场景A：签到打卡
   - 需要一定的随机性
   - 但不希望偏差太大
   - 推荐：±10~30秒
   
   场景B：数据采集
   - 需要较强的隐蔽性
   - 可以接受较大偏差
   - 推荐：±60~120秒
   
   场景C：系统同步
   - 需要精确时间
   - 不需要随机性
   - 推荐：0秒（无随机）
   ```

2. **用户偏好不同**
   ```
   用户A：保守型
   - 喜欢小范围随机
   - 担心偏差过大影响业务
   - 选择：±10秒
   
   用户B：激进型
   - 喜欢大范围随机
   - 追求最大隐蔽性
   - 选择：±120秒
   ```

3. **灵活性更高**
   ```
   固定±30秒：
   - 所有用户都一样
   - 无法满足个性化需求
   
   用户自定义：
   - 每个用户可以不同
   - 可以根据任务调整
   - 更加灵活
   ```

---

### 为什么限制最大值300秒？

**考虑因素**：

1. **实用性**
   ```
   ±5分钟的偏差已经很大了
   再大就失去了定时任务的意义
   ```

2. **用户体验**
   ```
   如果用户设定09:00
   结果在08:50或09:10执行
   会感到困惑
   ```

3. **合理性**
   ```
   大多数场景下
   ±1~2分钟已经足够
   ±5分钟是极端情况
   ```

## 🐛 故障排查

### 问题1：随机偏移输入框不显示

**症状**：
- 选择了"设定具体时间"
- 但没有看到随机偏移输入框

**解决**：
1. 检查HTML中是否有 `id="randomOffsetField"` 的元素
2. 确认CSS样式是否正确
3. 刷新页面重新加载

---

### 问题2：随机偏移值未保存

**症状**：
- 设置了随机偏移值
- 保存后重新打开，值恢复为默认值

**解决**：
1. 检查getFormData中是否包含：
   ```javascript
   data.randomOffsetSeconds = ...
   ```
2. 检查fillForm中是否包含：
   ```javascript
   randomOffsetInput.value = task.randomOffsetSeconds
   ```
3. 查看Storage中是否有该字段

---

### 问题3：随机偏移未生效

**症状**：
- 设置了随机偏移值
- 但日志显示"无随机偏移"

**解决**：
1. 检查calculateNextRunTime中是否读取了 `task.randomOffsetSeconds`
2. 确认maxOffset的值是否正确
3. 查看Console日志：
   ```javascript
   [任务调度] 设定时间 09:00，用户设置最大偏移 60秒，实际随机偏移 +42秒
   ```

---

### 问题4：随机范围不正确

**症状**：
- 设置了±60秒
- 但实际偏移超过60秒

**解决**：
1. 检查随机数生成公式：
   ```javascript
   const randomOffset = Math.floor(Math.random() * (maxOffset * 2 + 1)) - maxOffset;
   ```
2. 确认maxOffset的值
3. 验证公式计算：
   - maxOffset=60 → 60*2+1=121 → 0~120 → -60~+60 ✅

## 💡 最佳实践

### 1. 根据任务类型选择偏移范围

**推荐配置**：

| 任务类型 | 推荐偏移 | 理由 |
|---------|---------|------|
| 签到打卡 | ±10~30秒 | 需要一定随机性，但偏差不宜过大 |
| 数据采集 | ±60~120秒 | 需要较强隐蔽性，可接受较大偏差 |
| 系统同步 | 0秒 | 需要精确时间，不需要随机性 |
| 日常操作 | ±30秒（默认） | 平衡随机性和准确性 |

---

### 2. 测试不同偏移值

**方法**：
1. 创建多个任务，设置不同的偏移值
2. 观察几天的执行情况
3. 查看Console日志中的实际偏移
4. 选择最适合的值

**示例**：
```
任务A：±10秒 → 观察3天
任务B：±30秒 → 观察3天
任务C：±60秒 → 观察3天
→ 选择最合适的
```

---

### 3. 理解偏移值的含义

**重要概念**：
- **±N秒** = 偏移范围是 -N 到 +N
- **0秒** = 无随机，精确执行
- **每次重新计算** = 每天的偏移值不同

**示例**：
```
设置：±60秒
可能值：-60, -59, ..., 0, ..., +59, +60
总共：121种可能（60*2+1）
```

---

### 4. 监控实际执行情况

**方法**：
1. 定期查看Background Console日志
2. 记录实际执行时间和偏移值
3. 确认是否在预期范围内
4. 如有异常，及时调整

**日志示例**：
```javascript
[任务调度] 设定时间 09:00，用户设置最大偏移 60秒，实际随机偏移 +42秒，实际执行时间 09:00:42
[任务调度] 设定时间 09:00，用户设置最大偏移 60秒，实际随机偏移 -18秒，实际执行时间 08:59:42
```
