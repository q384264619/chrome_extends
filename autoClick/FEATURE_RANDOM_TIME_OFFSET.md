# 随机时间偏移功能

## 🎯 功能概述

本次更新为**每天定时任务**添加了**随机时间偏移**功能，避免在完全固定的时间点触发，使任务执行看起来更自然、更像真实用户行为。

---

## 🐛 问题背景

**原有行为**：
- 设定时间为 `09:00`，任务每天都在精确的 `09:00:00` 执行
- 长期运行后，容易被发现是自动化脚本
- 缺乏真实用户行为的随机性

**示例场景**：
```
第1天：09:00:00 执行
第2天：09:00:00 执行
第3天：09:00:00 执行
...
第100天：09:00:00 执行  ← 太规律了，容易被识别为脚本
```

---

## ✅ 解决方案

### 核心逻辑

在用户设定的时间基础上，添加一个**随机的秒数偏移**（±30秒）：

```javascript
// 生成 -30 到 +30 秒之间的随机数
const randomOffset = Math.floor(Math.random() * 61) - 30;

// 应用到目标时间
targetTime.setSeconds(targetTime.getSeconds() + randomOffset);
```

**效果**：
- ✅ 每次调度都重新计算随机偏移
- ✅ 每天的执行时间略有不同
- ✅ 看起来更像真实用户行为

---

## 🔧 技术实现

### calculateNextRunTime函数修改

```javascript
if (task.timeMode === 'specific' && task.execTime) {
    const [hours, minutes] = task.execTime.split(':').map(Number);
    targetTime = new Date(now);
    targetTime.setHours(hours, minutes, 0, 0);

    // ✅ 添加随机时间偏移（±30秒）
    const randomOffset = Math.floor(Math.random() * 61) - 30; // -30 到 +30
    targetTime.setSeconds(targetTime.getSeconds() + randomOffset);
    
    console.log(`[任务调度] 设定时间 ${task.execTime}，添加随机偏移 ${randomOffset}秒，实际执行时间 ${targetTime.toLocaleTimeString()}`);

    // 如果今天的时间已过，设置为明天
    if (targetTime <= now) {
        targetTime.setDate(targetTime.getDate() + 1);
        // 明天的时间也需要添加随机偏移
        const tomorrowRandomOffset = Math.floor(Math.random() * 61) - 30;
        targetTime.setSeconds(targetTime.getSeconds() + tomorrowRandomOffset);
        console.log(`[任务调度] 调整为明天，再次添加随机偏移 ${tomorrowRandomOffset}秒`);
    }
}
```

**关键点**：
1. **首次调度**：添加随机偏移（-30到+30秒）
2. **跨天调整**：如果时间已过需要调到明天，再次添加新的随机偏移
3. **日志输出**：记录随机偏移值，便于调试和验证

## 💡 设计理由

### 为什么选择 ±30 秒？

**考虑因素**：

1. **足够隐蔽**
   ```
   ±30秒的波动范围：
   - 不会太明显（不是±5分钟那么夸张）
   - 足以打破固定模式
   - 符合真实用户的操作习惯
   ```

2. **不影响用户体验**
   ```
   用户设定 09:00：
   - 最早：08:59:30
   - 最晚：09:00:30
   - 误差在可接受范围内
   ```

3. **技术合理性**
   ```
   Chrome Alarms API：
   - 精度通常为秒级
   - ±30秒在API能力范围内
   - 不会因为偏移导致闹钟失效
   ```

---

### 为什么每次都重新计算随机偏移？

**原因**：

1. **增加不可预测性**
   ```
   如果固定偏移：
   - 每天都 +15秒 → 仍然有规律
   - 容易被识别
   
   如果随机偏移：
   - 每天不同 → 无规律
   - 更难被识别
   ```

2. **模拟真实用户**
   ```
   真实用户：
   - 不会每天精确在同一秒操作
   - 会有自然的波动
   
   随机偏移：
   - 模拟这种波动
   - 更逼真
   ```

3. **避免模式识别**
   ```
   固定偏移的模式：
   Day1: 09:00:15
   Day2: 09:00:15
   Day3: 09:00:15
   → 容易被检测
   
   随机偏移的模式：
   Day1: 09:00:15
   Day2: 08:59:52
   Day3: 09:00:23
   → 难以检测
   ```

## 🐛 故障排查

### 问题1：随机偏移未生效

**症状**：
- 日志中没有显示随机偏移
- 执行时间仍然是精确的整点

**解决**：
1. 检查代码中是否有以下日志：
   ```javascript
   [任务调度] 设定时间 09:00，添加随机偏移 +15秒
   ```
2. 确认任务使用了 `timeMode === 'specific'`
3. 重新加载插件

---

### 问题2：偏移范围不正确

**症状**：
- 偏移超过±30秒
- 或者偏移始终为正/负

**解决**：
1. 检查随机数生成逻辑：
   ```javascript
   const randomOffset = Math.floor(Math.random() * 61) - 30;
   // Math.random() * 61 → 0 到 60.999...
   // Math.floor(...) → 0 到 60
   // - 30 → -30 到 +30
   ```
2. 确认使用的是 `Math.random()` 而不是其他方法

---

### 问题3：跨天后偏移丢失

**症状**：
- 今天的任务有偏移
- 明天的任务没有偏移

**解决**：
1. 检查跨天逻辑中是否再次添加偏移：
   ```javascript
   if (targetTime <= now) {
       targetTime.setDate(targetTime.getDate() + 1);
       const tomorrowRandomOffset = Math.floor(Math.random() * 61) - 30;
       targetTime.setSeconds(targetTime.getSeconds() + tomorrowRandomOffset);
   }
   ```
2. 确认日志中有"调整为明天，再次添加随机偏移"

## 📋 自定义偏移范围

如果需要调整随机偏移的范围，可以修改以下代码：

```javascript
// 当前：±30秒
const randomOffset = Math.floor(Math.random() * 61) - 30;

// 改为 ±15秒
const randomOffset = Math.floor(Math.random() * 31) - 15;

// 改为 ±60秒
const randomOffset = Math.floor(Math.random() * 121) - 60;

// 改为 0 到 +30秒（只正偏移）
const randomOffset = Math.floor(Math.random() * 31);
```

**公式**：
```javascript
// 范围：-N 到 +N
const randomOffset = Math.floor(Math.random() * (2*N + 1)) - N;

// 示例：
// N = 30 → -30 到 +30 → Math.random() * 61 - 30
// N = 15 → -15 到 +15 → Math.random() * 31 - 15
// N = 60 → -60 到 +60 → Math.random() * 121 - 60
```
