# 安装和测试指南

## 🎯 快速安装（3步完成）

### 步骤1：打开扩展程序管理页面

根据你的浏览器，在地址栏输入：

**Chrome / Edge:**
```
chrome://extensions/
```

**Firefox:**
```
about:debugging#/runtime/this-firefox
```

### 步骤2：启用开发者模式

- 找到页面右上角的"开发者模式"开关
- 点击开启

### 步骤3：加载插件

**Chrome / Edge:**
1. 点击左上角的"加载已解压的扩展程序"按钮
2. 浏览并选择文件夹：`/Users/petter.he/chrome_extends/autoClick`
3. 点击"选择"

**Firefox:**
1. 点击"临时载入附加组件"按钮
2. 浏览并选择文件：`/Users/petter.he/chrome_extends/autoClick/manifest.json`
3. 点击"打开"

### ✅ 安装成功确认

安装成功后，你会看到：
- 扩展列表中出现"自动点击助手"
- 浏览器工具栏显示靶心图标 🎯
- 可以正常点击和使用

## 🧪 功能测试

### 测试1：创建简单任务

1. **准备测试页面**
   - 打开 https://www.baidu.com
   
2. **获取选择器**
   - 右键点击"百度一下"按钮
   - 选择"检查"
   - 记下ID：`su`

3. **创建任务**
   - 点击浏览器工具栏的靶心图标 🎯
   - 点击"+ 添加任务"
   - 填写：
     ```
     任务名称：测试点击
     目标元素CSS选择器：#su
     执行时间：不设定时间
     执行频率：不设定频率
     触发模式：单次触发
     ```
   - 点击"保存"

4. **验证结果**
   - ✓ 任务立即执行
   - ✓ 百度搜索被触发
   - ✓ 右上角显示通知
   - ✓ 任务状态变为"已完成"

### 测试2：创建定时任务

1. **创建任务**
   - 点击"+ 添加任务"
   - 填写：
     ```
     任务名称：每分钟测试
     目标元素CSS选择器：#su
     执行时间：不设定时间
     执行频率：设定时间间隔 → 1（分钟）
     触发模式：循环触发 → 每天
     ```
   - 点击"保存"

2. **验证结果**
   - ✓ 任务每分钟执行一次
   - ✓ 每次执行都有通知
   - ✓ 任务保持"启用"状态

3. **清理测试**
   - 点击任务的"删除"按钮
   - 或点击"禁用"按钮停止

### 测试3：编辑和删除

1. **编辑任务**
   - 点击任意任务的"编辑"按钮
   - 修改任务名称
   - 点击"保存"
   - ✓ 任务信息已更新

2. **禁用/启用任务**
   - 点击"禁用"按钮
   - ✓ 任务状态变为"禁用"
   - 点击"启用"按钮
   - ✓ 任务状态变为"启用"

3. **删除任务**
   - 点击"删除"按钮
   - 确认删除
   - ✓ 任务从列表中消失

## 🔍 调试方法

### 查看Popup日志

1. 右键点击插件图标
2. 选择"检查弹出内容"
3. 查看Console标签

### 查看Background日志

**Chrome/Edge:**
1. 进入 `chrome://extensions/`
2. 找到"自动点击助手"
3. 点击"service worker"链接
4. 查看Console

**Firefox:**
1. 进入 `about:debugging#/runtime/this-firefox`
2. 找到"自动点击助手"
3. 点击"检查"
4. 查看Console

### 查看Content Script日志

1. 在任意网页按 F12 打开开发者工具
2. 切换到Console标签
3. 查找以 `[自动点击助手]` 开头的日志

## ❓ 常见问题

### Q1: 图标没有显示？
**A:** 这是正常的，因为我们使用的是程序生成的简单图标。不影响功能使用。

### Q2: 任务没有执行？
**A:** 检查以下几点：
- 任务是否"启用"状态
- CSS选择器是否正确（在控制台测试）
- 元素是否在页面上可见
- 查看Console日志了解详细错误

### Q3: 如何测试CSS选择器？
**A:** 在浏览器控制台（F12）中输入：
```javascript
document.querySelector('#your-selector')
```
如果返回元素对象，说明选择器正确。

### Q4: 插件会影响浏览器性能吗？
**A:** 不会。插件只在需要时执行任务，后台占用极小。

### Q5: 卸载插件？
**A:** 
1. 进入扩展程序管理页面
2. 找到"自动点击助手"
3. 点击"移除"或"卸载"

## 📝 使用提示

### 最佳实践

1. **命名规范**
   - 给任务起个清晰的名字
   - 例如："每日签到"、" hourly刷新"

2. **选择器优化**
   - 优先使用ID选择器（最快）
   - 其次使用类选择器
   - 避免过于复杂的选择器

3. **时间设置**
   - 定时任务建议提前5-10分钟
   - 考虑网络延迟和页面加载时间

4. **任务管理**
   - 定期清理已完成的任务
   - 禁暂时不需要的任务而不是删除

### 注意事项

⚠️ **重要提醒：**
- 确保目标网页在任务执行时是打开的
- 某些网站可能有反自动化机制
- 不要设置过短的执行间隔（建议≥1分钟）
- 尊重网站的使用条款
