# 快速开始指南

## 🚀 5分钟上手自动点击助手

### 第一步：安装插件

1. **打开扩展程序页面**
   - Chrome/Edge: 在地址栏输入 `chrome://extensions/` 或 `edge://extensions/`
   - Firefox: 在地址栏输入 `about:debugging#/runtime/this-firefox`

2. **启用开发者模式**
   - 找到并开启右上角的"开发者模式"开关

3. **加载插件**
   - 点击"加载已解压的扩展程序"（Chrome/Edge）
   - 或点击"临时载入附加组件"（Firefox）
   - 选择 `/Users/petter.he/chrome_extends/autoClick` 文件夹

4. **确认安装**
   - 在浏览器工具栏看到靶心图标 🎯 即表示安装成功

### 第二步：创建第一个任务

让我们创建一个简单的测试任务：

1. **打开任意网页**
   - 例如：https://www.baidu.com

2. **找到要点击的元素**
   - 右键点击"百度一下"按钮
   - 选择"检查"
   - 在开发者工具中，你会看到类似 `<input id="su" type="submit" value="百度一下">`

3. **复制CSS选择器**
   - 在开发者工具中右键该元素
   - 选择"复制" > "复制CSS选择器"
   - 或者直接记住：`#su`

4. **打开插件**
   - 点击浏览器工具栏中的靶心图标 🎯

5. **添加任务**
   - 点击"+ 添加任务"按钮
   - 填写以下信息：
     ```
     任务名称：测试点击
     目标元素CSS选择器：#su
     执行时间：不设定时间（立即执行）
     执行频率：不设定频率
     触发模式：单次触发
     ```
   - 点击"保存"

6. **查看结果**
   - 任务会立即执行
   - 你会看到百度搜索被执行
   - 右上角会显示通知："任务 '测试点击' 已成功执行"

### 第三步：创建定时任务

现在创建一个每天定时执行的任务：

1. **点击"+ 添加任务"**

2. **填写配置**
   ```
   任务名称：每日签到
   目标元素CSS选择器：.checkin-button
   执行时间：设定具体时间 → 09:00
   执行频率：不设定频率
   触发模式：循环触发 → 每天
   ```

3. **保存**
   - 每天早上9点，插件会自动查找并点击页面上的 `.checkin-button` 元素

### 获取CSS选择器的技巧

#### 方法1：使用开发者工具（推荐）
1. 右键点击目标元素
2. 选择"检查"
3. 在Elements面板中右键该元素
4. 选择"复制" > "复制CSS选择器"

#### 方法2：手动编写
- **ID选择器**：`#elementId`
- **类选择器**：`.className`
- **标签选择器**：`button`
- **属性选择器**：`[type="submit"]`
- **组合选择器**：`form .submit-btn`

#### 方法3：在控制台测试
打开浏览器控制台（F12），输入：
```javascript
document.querySelector('#your-selector')
```
如果返回元素，说明选择器正确。

### 常见问题排查

#### ❌ 任务没有执行？
**检查清单：**
- [ ] 任务是否处于"启用"状态？
- [ ] 当前页面是否包含目标元素？
- [ ] CSS选择器是否正确？（在控制台测试）
- [ ] 元素是否可见？（不是display:none）
- [ ] 元素是否可交互？（不是disabled状态）

#### ✅ 调试步骤：
1. 打开浏览器控制台（F12）
2. 切换到Console标签
3. 输入选择器测试：`document.querySelector('你的选择器')`
4. 查看是否有日志输出：`[自动点击助手] ...`

### 高级技巧

#### 1. 多任务管理
- 可以创建多个任务，互不影响
- 每个任务独立调度和执行
- 随时启用/禁用任务

#### 2. 智能跳过节假日
- 在循环触发设置中勾选"智能跳过节假日期"
- 适合工作日任务，自动跳过周末和节假日

#### 3. 组合使用时间和频率
```
设定时间：14:30
设定频率：30分钟
结果：14:30首次执行，之后每30分钟执行一次
```
