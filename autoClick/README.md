# 自动点击助手 - 浏览器插件

一款功能强大的浏览器插件，支持根据用户设定的时间、频率、目标元素自动完成点击动作。

## 功能特性

- ✅ **多任务管理**：创建和管理多个自动点击任务
- ✅ **灵活的时间设置**：支持立即执行或指定具体时间
- ✅ **频率控制**：可设置执行间隔时间（分钟）
- ✅ **触发模式**：
  - 单次触发：执行一次后自动停止
  - 循环触发：按天/周/月循环执行
- ✅ **智能跳过节假日**：可选功能
- ✅ **可视化界面**：友好的用户界面，易于操作
- ✅ **跨页面执行**：在所有打开的标签页中查找并点击目标元素

## 安装说明

### Chrome / Edge 浏览器

1. 打开浏览器，进入扩展程序管理页面
   - Chrome: 地址栏输入 `chrome://extensions/`
   - Edge: 地址栏输入 `edge://extensions/`

2. 开启右上角的"开发者模式"

3. 点击"加载已解压的扩展程序"

4. 选择本项目中的 `autoClick` 文件夹

5. 插件安装完成，会在浏览器工具栏显示图标

### Firefox 浏览器

1. 地址栏输入 `about:debugging#/runtime/this-firefox`

2. 点击"临时载入附加组件"

3. 选择 `autoClick/manifest.json` 文件

4. 插件加载完成

## 使用指南

### 创建新任务

1. 点击浏览器工具栏中的插件图标
2. 点击"+ 添加任务"按钮
3. 填写任务配置：
   - **任务名称**：给任务起个名字（如：每日签到）
   - **目标元素CSS选择器**：要点击的元素的选择器
     - ID选择器：`#submitBtn`
     - 类选择器：`.login-button`
     - 属性选择器：`[data-action="submit"]`
   - **执行时间**：
     - 不设定时间：立即执行
     - 设定具体时间：在指定时间执行（如：14:30）
   - **执行频率**：
     - 不设定频率：按触发模式执行
     - 设定时间间隔：每隔X分钟执行一次
   - **触发模式**：
     - 单次触发：执行一次后停止
     - 循环触发：持续执行
       - 每天：每天都执行
       - 每周：选择星期几执行
       - 每月：选择每月的哪一天执行
4. 点击"保存"按钮

### 管理任务

在任务列表中，每个任务显示以下信息：
- 任务名称
- 目标元素选择器
- 执行时间
- 执行频率
- 触发模式
- 当前状态（启用/禁用/已完成）

每个任务有三个操作按钮：
- **编辑**：修改任务配置
- **启用/禁用**：切换任务状态
- **删除**：删除任务

### 获取CSS选择器

1. 在网页上右键点击要点击的元素
2. 选择"检查"或"审查元素"
3. 在开发者工具中右键点击该元素
4. 选择"复制" > "复制CSS选择器"
5. 粘贴到插件的配置中

常见选择器示例：
```css
/* ID选择器 */
#submit-btn

/* 类选择器 */
.login-button
.btn-primary

/* 属性选择器 */
[data-action="submit"]
[type="submit"]

/* 组合选择器 */
form button[type="submit"]
.container .btn-login
```

## 技术实现

### 架构设计

- **popup.html/popup.js**：用户界面，任务列表和配置表单
- **background.js**：后台服务，负责任务调度和执行
- **contentScript.js**：内容脚本，在页面中执行点击操作
- **chrome.storage**：本地存储，保存任务配置

### 核心功能

1. **任务调度**：使用 Chrome Alarms API 实现精确的任务调度
2. **页面交互**：通过 Content Script 在页面中查找并点击元素
3. **数据持久化**：使用 Chrome Storage API 保存任务配置
4. **通知系统**：任务执行时发送桌面通知

## 注意事项

1. **权限说明**：
   - `storage`：保存任务配置
   - `activeTab`：访问当前活动标签页
   - `scripting`：在页面中注入脚本
   - `alarms`：定时调度任务
   - `notifications`：发送执行通知
   - `<all_urls>`：在所有网站中查找和点击元素

2. **元素可见性**：只会点击可见且可交互的元素

3. **页面刷新**：某些任务可能需要页面保持打开状态

4. **浏览器兼容性**：支持 Chrome、Edge、Firefox 等主流浏览器

## 常见问题

### Q: 任务没有执行？
A: 检查以下几点：
- 任务是否处于"启用"状态
- 当前页面是否包含目标元素
- CSS选择器是否正确
- 元素是否可见且可交互

### Q: 如何测试选择器？
A: 在浏览器控制台（F12）中输入：
```javascript
document.querySelector('你的选择器')
```
如果能找到元素，说明选择器正确。

### Q: 任务执行后状态不变？
A: 刷新插件弹窗页面，状态会更新。

### Q: 支持跨域页面吗？
A: 是的，插件可以在所有网站上运行。
