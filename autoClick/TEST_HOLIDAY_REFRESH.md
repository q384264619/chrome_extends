# 节假日刷新功能测试指南

## 🎯 测试目标

验证节假日刷新按钮是否正常工作，不再卡在"刷新中..."状态。

## 📋 前置条件

1. ✅ 插件已加载到浏览器
2. ✅ 浏览器可以访问互联网
3. ✅ 开发者工具已打开（F12）

## 🧪 测试步骤

### 测试1：基本刷新功能

**步骤**：
1. 点击浏览器工具栏的插件图标 🎯
2. 找到右上角的"🔄 节假日"按钮
3. 点击该按钮
4. 观察按钮状态变化

**预期结果**：
```
初始状态: "🔄 节假日"
点击后:   "⏳ 刷新中..." (持续1-3秒)
成功后:   "✅ 已更新" (持续2秒)
恢复:     "🔄 节假日"
```

**Console日志**：
```
[节假日] 开始获取节假日数据...
[节假日] 成功获取 XX 个节假日
[节假日] 缓存已保存
[节假日] 刷新成功
```

**失败情况**：
```
如果显示"❌ 失败"并弹出错误提示框
→ 检查网络连接
→ 查看Console中的详细错误信息
```

## 🔍 故障排查

### 问题1：按钮一直显示"刷新中..."

**可能原因**：
1. Service Worker 未正确加载
2. holidayManager 对象未定义
3. 消息通信失败

**解决方法**：
```javascript
// 1. 检查Service Worker状态
// 在 chrome://extensions/ 页面
// 查看"service worker"链接是否可点击

// 2. 在Console中检查
console.log(typeof holidayManager);
// 应该输出: "object"

// 3. 重新加载插件
// chrome://extensions/ → 点击刷新按钮 🔄
```

---

### 问题2：显示"❌ 失败"

**可能原因**：
1. 网络连接问题
2. 数据源不可用
3. CORS限制

**解决方法**：
```javascript
// 1. 检查网络连接
fetch('https://www.shuyz.com/')
  .then(() => console.log('网络正常'))
  .catch(err => console.error('网络错误:', err));

// 2. 手动测试数据源
fetch('https://www.shuyz.com/githubfiles/china-holiday-calender/master/holidayCal.ics')
  .then(r => r.text())
  .then(text => console.log('数据获取成功，长度:', text.length))
  .catch(err => console.error('数据源错误:', err));

// 3. 清除缓存重试
holidayManager.clearCache().then(() => {
    return holidayManager.fetchHolidays();
});
```

---

### 问题3：Console没有日志

**可能原因**：
1. Service Worker 的Console未打开
2. 日志级别过滤

**解决方法**：
```
1. 打开Service Worker的Console：
   - chrome://extensions/
   - 找到"自动点击助手"
   - 点击"service worker"链接
   - 这会打开专门的Console窗口

2. 确保日志级别设置为"All"或"Info"
```

---

### 问题4：节假日判断不准确

**可能原因**：
1. 数据源过时
2. 缓存数据过期
3. 解析逻辑错误

**解决方法**：
```javascript
// 1. 手动刷新获取最新数据
// 点击"🔄 节假日"按钮

// 2. 检查缓存时间
chrome.storage.local.get(['holidayCache'], (result) => {
    console.log('缓存数据:', result.holidayCache);
});

// 3. 清除缓存重新获取
holidayManager.clearCache();
// 然后点击刷新按钮
```
