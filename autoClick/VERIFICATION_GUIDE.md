4. 等待1-2秒，任务应该自动执行
5. 查看Background Console：

## 🐛 故障排查

### 问题1：任务创建后不显示

**检查**：
```javascript
// 在Popup Console执行
chrome.storage.sync.get(['tasks'], r => console.log('任务:', r.tasks));
```

**解决**：
- 刷新插件
- 清除Storage重试

---

### 问题2：任务不执行

**检查**：
```javascript
// 在Background Console执行
chrome.alarms.getAll(a => console.log('闹钟:', a));
```

**解决**：
- 确认任务已启用
- 确认任务状态不是completed
- 确认目标页面已打开

---

### 问题3：消息通信失败

**症状**：Console显示"Background未响应"

**解决**：
1. 检查Background Service Worker是否运行
2. 点击"service worker"链接看是否有错误
3. 重新加载插件
